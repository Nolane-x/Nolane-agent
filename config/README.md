# Configuration

This directory contains canonical product identity, release identity, platform capability truth, update configuration and model-management configuration for Nolane Agent.

The public version is controlled by `product-identity.json` and `release-identity.json`. The supported line is `0.0.N`.

`update.json` is intentionally disabled in 0.0.0 until signed update trust is verified. `update.example.json` documents the same safe default.
