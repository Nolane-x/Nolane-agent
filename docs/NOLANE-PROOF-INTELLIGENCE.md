# Nolane Agent — Proof Intelligence

## Baseline

Architecture planning uses a sanitized external-reference capability baseline covering multi-agent coordination, goal completion, self-verification, background work, browser automation and gateway lifecycle. Nolane does not treat feature-count parity as a meaningful superiority target; only independently reproducible behavior and evidence count.

## Nolane-only depth added in this checkpoint

### Proof-carrying missions

A mission is compiled into a claim graph with positive evidence obligations, falsification probes, independent verifier requirements, rollback bindings, and explicit deployment authorization. A model saying that work is complete is never sufficient.

### Causal repository twin

Files, symbols, tests, contracts, and runtime surfaces form a bounded causal graph. Nolane predicts blast radius before a change, excludes stale edges, records false positives and false negatives, and recalibrates confidence only from observed verification outcomes.

### Adversarial solution tournament

Candidate solutions are separated into proposer, falsifier, and verifier lanes. Confirmed critical counterexamples defeat a candidate even when its self-reported correctness is high. No valid candidate produces a real-probe requirement instead of a guessed winner.

### Adaptive small/large model governance

Nolane chooses the smallest model with sufficient calibrated reliability for low-risk work. High-risk work escalates to the strongest admissible model plus an independent verifier. Private tasks remain local. Outcome learning is bounded, and model promotion always requires an explicit human approval receipt.

## Claim boundary

Architecture and local conformance are implemented and measured. A comparative performance statement requires an independently supplied external-reference run artifact under the same model, same machine, same token budget, same permissions, same task distribution, and equivalent tool access. No mock or self-authored competitor score is accepted.
