# Forge Studio 2.26.0 — Memory, Skill & Resource Operating System

## Release identity

- Version: `2.26.0`
- Theme: governed memory lifecycle, model-time replay, compositional skill compilation, stability–plasticity protection, utility-based resource admission, and bounded content-addressed artifacts.
- Frontier audit: `854 verified_source_test`, `77 partial`, `56 external_gate`, `163 not_implemented`.

## Added

- Versioned Memory Operating System with `suppress`, `deprioritize`, `invalidate`, `archive`, `abstract`, and privacy `delete` operations.
- Subconscious, episodic, semantic-schema, and exception layers with validity intervals and source provenance.
- Shadow-only governed memory policy and model-time Scheduled Replay.
- Compositional Skill Compiler, transfer evaluation, lineage, rollback, and Stability–Plasticity Guard.
- Utility-per-MB-second resource admission, signed leases, `rssMbSeconds`, viability prediction, and Local Device Doctor profiles.
- Content-addressed artifact storage with deduplication, range reads, bounded projections, and privacy tombstones.
- Lazy Memory–Skill–Resource Plane and identity-bound resource cleanup.

## Non-claims

This release does not change production memory policy automatically, does not automatically promote skills, does not certify direct OS budget enforcement on every platform, does not certify long-term skill survival, does not include a cold/warm RSS benchmark across representative machines, and does not claim benchmark superiority over competing agents.
