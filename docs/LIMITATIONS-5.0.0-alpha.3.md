# Nolane Agent 5.0.0-alpha.3 — Limitations and Non-Claims

The authoritative requirement ledger is `docs/feature-audit-5.0.0-alpha.3.json`; the complete open-item list is `docs/REMAINING-GAPS-5.0.0-alpha.3.md`.

## Explicit limitations

- No Nolane foundation model has been trained or promoted by this release.
- The small-model subsystem is a verified runtime foundation, not a capability-parity result.
- The legacy external reference remains third-party MIT research material with provenance; it is not relabeled as Nolane-owned code.
- NolaneNative execution is disabled by default and requires an explicit compatibility decision.
- Fixture evals only certify evaluator plumbing and carry `claimAllowed=false`.
- Windows artifacts are built and structurally verified in the release matrix, but this environment does not provide an independent Windows GUI/user-flow attestation.
- No provider credential was used to prove an autonomous model-real coding run.
- Open requirements remain open until an exact production entrypoint, exact test and fresh evidence receipt exist.
