# Nolane Agent 5.0.0-beta.5 — Limitations

Beta.5 converts additional shared runtime behavior into Nolane-native code, but it does not prove universal provider, platform or GUI parity.

Authoritative V5 evidence: `docs/feature-audit-5.0.0-beta.5.json` and `docs/REMAINING-GAPS-5.0.0-beta.5.md`.

The Native Core Conformance Catalog contains **69 behavioral contracts**, of which **46 verified contracts** are locally proven and **23 external contracts** require external evidence. It tracks **2,110 upstream source/config candidate paths**, including **387 verified upstream paths**.

Provider-real transports, messenger credentials, remote execution infrastructure, real browser/computer-use journeys, Windows installer execution, Windows 8 GB performance, screen-reader testing, responsive visual regression and independent competitor benchmarks remain external.

The legacy external runtime and archive remain absent from production and release packages. Historical attribution and audit inventory are retained only as non-executable evidence.
