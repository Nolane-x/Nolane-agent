# Forge Studio 2.21.0 verification contract

The release is accepted only when the Full Release Matrix passes on a clean commit. The new required `repository-intelligence-fabric` gate verifies:

- explicit embedding-provider identity, capabilities, model digest, and degraded fallback;
- an optional lazy ONNX provider contract without claiming a bundled or operated production model;
- bounded two-stage candidate narrowing and semantic reranking;
- quantized vector persistence and chunk-level content-addressed reuse;
- branch/head/dirty-state provenance and stale snapshot rejection;
- a citation-bound Repository Digital Twin with explicit unknown runtime relations;
- lazy Repository Intelligence Fabric activation and lexical continuity under semantic suspension;
- unchanged `src/app.mjs` composition budgets;
- honest 1,150-item audit counts and explicit non-claims.

The deterministic measurement uses an injected local semantic adapter to exercise the provider contract. It is not a production ONNX model, an independent unseen-repository benchmark, or evidence that Forge Studio outperforms another coding agent.
