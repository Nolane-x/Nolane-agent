# Forge Studio 2.22.0 verification contract

The release is accepted only when the required Full Release Matrix passes on a clean commit. The `polyglot-runtime-intelligence` gate verifies:

- honest language capability states and real target-runner binary probes;
- Tree-sitter missing-runtime non-claim;
- bounded LSP contract operations and session lifecycle;
- source classification and framework evidence;
- relationship provenance and ambiguity preservation;
- permission-bound runtime redaction;
- architecture drift findings and blocking policy;
- unchanged application composition budgets;
- honest 1,150-item audit counts and explicit limitations.

A fixture contract is not production language-server certification, and a version probe is not end-to-end project validation.
