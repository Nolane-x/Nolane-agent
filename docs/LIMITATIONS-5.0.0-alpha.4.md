# Nolane Agent 5.0.0-alpha.4 — Limitations and Non-Claims

The authoritative requirement ledger is `docs/feature-audit-5.0.0-alpha.4.json`; the complete list of **23 open requirements** is `docs/REMAINING-GAPS-5.0.0-alpha.4.md`.

## Explicit limitations

- No Nolane foundation model has been trained, fine-tuned or promoted by this release.
- Distillation, recursive, symbolic, plasticity and curriculum modules are verified runtime foundations; they are not evidence of model capability parity.
- Recursive same-FLOP/same-parameter ablation, quantization stability and out-of-distribution transfer remain unverified.
- The symbolic compiler currently supports bounded declarative text transformations; real AST codemods, SMT and Datalog adapters remain open.
- Specialist mmap/lazy-load completeness and multi-agent-to-single-policy distillation remain open.
- Learned adaptation policies and latent memory experts remain open.
- Same-quality cost benchmarking requires real model cohorts and remains open.
- No provider credential was used to prove a provider-real autonomous coding run.
- Windows artifacts may be structurally built by the matrix, but independent Windows 8 GB GUI, memory, CPU, latency and visual certification remains open.
- WCAG 2.2 AA, full responsive layout and visual/performance budgets remain open until independently measured.
- The legacy external reference remains third-party MIT research material with Nous Research attribution and transformation provenance. It is not relabeled as Nolane-owned source, and production execution remains disabled.
- Fixture evals certify evaluator plumbing only and retain `claimAllowed=false`.
