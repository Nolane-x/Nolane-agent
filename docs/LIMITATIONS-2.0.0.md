# Forge Studio 2.0.0 — remaining limits

The item-level source of truth is `feature-audit-2.0.0.json`. The exhaustive open-item report is `REMAINING-GAPS-2.0.0.md`.

## Agent mode boundaries

The local runtime implements twenty canonical modes. The following related capabilities remain evidence-bound external gates rather than local-mode claims:

- hosted pull-request execution against a real provider and repository account;
- production cloud sandbox operation and durable hosted workers;
- enterprise-hosted identity, organization policy, billing, and compliance operation.

## Code intelligence boundaries

Forge Studio still does not claim Tree-sitter incremental parse trees, general AST queries, language-general AST patching, a complete inheritance graph, issue/PR-to-code indexing, or independent certification of provider-backed semantic embeddings unless the audit explicitly changes those items.

## Platform and production boundaries

Native OS isolation parity, Authenticode, Apple notarization, live enterprise IdP/SCIM conformance, hosted cloud conformance, marketplace approval, and independent comparative benchmarks require external infrastructure or evidence. Exact completion conditions for every open item are listed in `REMAINING-GAPS-2.0.0.md`.
