# Nolane Agent 5.0.0-beta.2 — Feature Completeness Audit

## Nolane V5 registry

The canonical Nolane V5 registry contains 198 requirements. Beta.2 classifies 193 as `verified_source_test` and 5 as `not_implemented`.

`verified_source_test` means the item has a production entrypoint, exact test, current evidence hashes and a replay receipt. It does not mean independent third-party certification, provider-real autonomy, Windows runtime certification or model superiority. Source-file count is never accepted as proof.

The five remaining V5 items are Windows 8 GB performance, runtime/manual accessibility and responsive certification, runtime UI resource/visual budgets, and provider-real Windows dogfooding. They remain visible in `docs/REMAINING-GAPS-5.0.0-beta.2.md` and `docs/feature-audit-5.0.0-beta.2.json`.
