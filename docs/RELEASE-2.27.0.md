# Forge Studio 2.27.0 — Collaboration & Agent-Native Experience

## Release identity

- Version: `2.27.0`
- Theme: typed multi-agent shared state, joint commitments, adaptive topology, semantic merge, deterministic browser replay, governed review/playback/steering, and shared web + VS Code mission state.
- Frontier audit: `883 verified_source_test`, `96 partial`, `56 external_gate`, `115 not_implemented`.

## Added

- Versioned Shared Blackboard for facts, assumptions, blockers, artifacts, ownership and per-agent beliefs with provenance, TTL, fencing and conflict preservation.
- Joint Commitment Ledger for goals, roles, interface contracts, dependencies, handoffs, renegotiation and deadlock recovery.
- Adaptive multi-agent topology recommendations that choose the smallest sufficient communication graph under risk, independence and resource constraints.
- Semantic merge analysis for incompatible API assumptions, behavioral conflicts and duplicate logic even when Git reports no textual conflict.
- Deterministic browser journey replay with versioned scripts, seeds, state reset, network/action allowlists, injection/download guards, repeated-run divergence and flake receipts.
- Risk-aware Review Queue, bounded Artifact Playback rewind plans and capability-gated mission steering.
- Shared local HTTP, web UI and VS Code mission-state surfaces backed by one lazy Collaboration & Experience Plane.

## Non-claims

This release does not automatically create an unbounded swarm, does not certify a universal semantic merge proof, does not treat screenshots as a visual oracle, does not execute rewind or auto-merge, does not certify JetBrains parity or cross-platform computer-use production behavior, and does not claim benchmark superiority over competing agents.
