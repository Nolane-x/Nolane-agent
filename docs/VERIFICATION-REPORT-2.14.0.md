# Forge Studio 2.14.0 verification contract

The release is accepted only when the required Full Release Matrix passes on a clean commit. The dedicated `mission-completion-runtime-readiness` gate verifies ordered architecture stages, version-matched IDE evidence, desktop multi-agent evidence, cloud-last eligibility without an operational claim, bounded task resource envelopes, reasoning/execution separation, the deterministic mission completion graph, local Git review and capability-gated commit delegation, authenticated API wiring, Docker daemon probing, mount validation, socket-escape denial, item-level audit movement, and explicit limitations.

The Node suite, runtime smoke, SDK tests, ForgeOS validation, artifact packaging, fresh-source reconstruction, and archive-integrity gates remain required. A source-level or Linux-only result does not replace external Windows, macOS, cloud, hosted PR, marketplace, or independent certification evidence.
