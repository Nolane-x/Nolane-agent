# Nolane Agent 5.0.0-alpha.2 verification contract

A release is accepted only when every required Full Release Matrix gate passes on the release commit. The matrix includes Nolane requirement generation, evidence freshness/quality, UI capability coverage, packaging, exact published source ZIP clean-room replay, fresh-source reconstruction and archive integrity.

Verified Nolane requirements require a named production entrypoint, exact automated test, source/test SHA-256 and replay receipt. Stable release certification is not granted by this alpha report.
