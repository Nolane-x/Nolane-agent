# Nolane Agent 5.0.0-beta.2 — Limitations

The legacy external runtime and archive remain absent, but removal is not proof of complete behavioral parity.

The native-core catalog contains **60 behavioral contracts**: **26 verified contracts** and **34 external contracts**. It maps all **2,110 upstream source/config candidate paths** with no unmapped or not-implemented candidate, but 1,938 candidate paths currently inherit an external-certification state. A broad external contract is a tracked obligation, not proof that its upstream behavior has already been exercised.

External work includes provider-real credentials and transports, messaging platforms, browser/computer-use journeys, remote execution, external memory and scheduler providers, media/voice services, OAuth and secret stores, desktop/Windows installer execution, keyboard/screen-reader and visual certification, and matched independent benchmark evidence.

The Master Acceptance Ledger reports 1,405 canonical requirements: 1,298 verified and 107 external. It does not use file existence as capability proof.

Authoritative V5 evidence: `docs/feature-audit-5.0.0-beta.2.json` and `docs/REMAINING-GAPS-5.0.0-beta.2.md`.
