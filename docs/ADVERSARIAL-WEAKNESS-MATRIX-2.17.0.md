# Forge Studio 2.17.0 — adversarial weakness matrix

| Area | 2.16 exposure | 2.17 response | Remaining weakness | Next evidence-driven action |
|---|---|---|---|---|
| Provider/browser process cost | Subagents could multiply provider, browser and terminal processes | Shared keyed leases, pressure admission, attribution and bounded queueing | One-shot CLI adapters are not persistent multiplexed hosts; process-tree memory is not fully attributed | Add protocol-specific persistent hosts only where supported; measure child process trees per mission |
| Repository intelligence load | Lexical, semantic and graph work could fan out independently | Shared priority scheduler, generation coalescing, stale cancellation and semantic pressure policy | Relationship/LSP/build/coverage updates are not all one journal; polyglot depth remains uneven | Extend the journal to relationship/LSP/build/runtime evidence and managed grammar packs |
| Static swarm | Planner could not freely add/revoke/revise work after evidence arrived | Mutable wave graph with bounded reconciler mutations and stop decisions | Reconciler intelligence still depends on model/evidence quality; semantic conflicts are not solved | Replay real failure clusters and compare deterministic/model-led reconciliation under held-out tasks |
| Ownership collision | Static path ownership could create churn | Known path/symbol collisions serialize with receipts | Undeclared/generated/runtime ownership can escape detection | Derive symbol ownership from LSP/AST/build graph and verify candidate commits before merge |
| Runtime observability | Resource limits existed but provider/browser/index queues were separate | Runtime status exposes work-fabric snapshots and mission attribution | No unified per-mission process-tree cost ledger yet | Add child-process CPU/RSS/FD accounting and cost/outcome correlation |
| Browser completion | Browser primitives existed without full repair/replay receipts | Browser actions now share admission | DOM/a11y/network/console/screenshot/video journey verification remains incomplete | Build Playwright journey receipts and a demo-repair-replay release gate |
| Product UX | Navigation exposes many centers | No new dashboard added in 2.17 | Information architecture remains dense | Collapse navigation into Mission, Work and Evidence shells after runtime proof |
| Hosted lifecycle | PR/CI/deploy remain external | No false local claim | Issue→PR→CI→repair is incomplete | Add least-privilege provider adapters and human merge gate on operated infrastructure |
