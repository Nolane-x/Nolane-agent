# Forge Studio 2.23.0 verification contract

The release is accepted only when the required Full Release Matrix passes on a clean commit. The `cognitive-decision-kernel` gate verifies:

- posterior dispersion blocks durable-memory writes and concentrated evidence permits them;
- alternative hypotheses survive until explicitly falsified;
- the selected probe maximizes information value under token, RAM, time and reversibility costs;
- missing binaries and stale memory route only to responsible subsystems;
- agency and episode receipts store expected-versus-actual outcomes without raw commands or transcripts;
- failed strategies are blocked inside a recovery lease;
- commits are denied before sufficient evidence and allowed only after bounded verification;
- stop gates honor verified criteria, marginal information gain and unresolved critical risks;
- lazy runtime integration and application composition budgets remain intact;
- the 1,150-item audit and all non-claims remain honest.

The measurement is deterministic Core behavior evidence. It is not an independent agent-quality benchmark or evidence of comparative superiority.
