# Nolane Agent 5.0.0-beta.6 — Limitations

Beta.6 converts additional MCP, browser-supervision, delegation, PTY, gateway-recovery and local-media runtime behavior into Nolane-native code, but it does not prove universal provider, platform or GUI parity.

Authoritative V5 evidence: `docs/feature-audit-5.0.0-beta.6.json` and `docs/REMAINING-GAPS-5.0.0-beta.6.md`.

The Native Core Conformance Catalog contains **75 behavioral contracts**, of which **52 verified contracts** are locally proven and **23 external contracts** require external evidence. It tracks **2,110 upstream source/config candidate paths**, including **413 verified upstream paths**.

Provider-real transports, messenger credentials, remote execution infrastructure, real browser/computer-use journeys, Windows installer execution, Windows 8 GB performance, screen-reader testing, responsive visual regression and independent competitor benchmarks remain external.

Nolane Native is the only product runtime owned and shipped by Nolane Agent. External runtime archives, compatibility packs, adapters and executable paths are excluded; runtime purity is verified for source and release artifacts.
