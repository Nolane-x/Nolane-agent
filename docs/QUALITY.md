# Quality and verification

## Gate classes
- **Unit/runtime:** Node and Go tests.
- **Core regression:** agent loop and structured subagent orchestration.
- **Release identity:** one 0.0.x version across package, product, SDK, extension, manifest and README.
- **UI:** deterministic build, tokens/capabilities and targeted accessibility/runtime evidence.
- **Platform:** Linux/Windows/macOS smoke validation in GitHub Actions.
- **Security:** CodeQL plus dependency/configuration checks.

A passing source test does not prove real-machine performance, signing, notarization, accessibility certification or provider-real success. Those claims remain unmade until measured by the appropriate evidence class.
