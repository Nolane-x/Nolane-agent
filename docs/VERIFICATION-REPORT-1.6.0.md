# Forge Studio 1.6.0 verification contract

Date: 2026-07-29

The required command is:

```bash
npm run release:matrix
```

Evidence is written to `release/matrix-1.6.0/`, bound to the exact Git commit, and every required gate must pass.

## Trace & Evidence evidence

- Project/mission/task scoped event pagination.
- Recursive secret redaction and public-field bounding.
- Verification evidence join and receipt/artifact graph derivation.
- Deterministic failure clustering and claim projection.
- Immutable content-addressed evidence export without local paths.
- Authenticated HTTP routes bound to the real principal.
- Lazy Timeline, Receipt Graph, Failures, Claims, and Exports UI.
- Futuristic visual markers and reduced-motion regression coverage.
- Dedicated `trace-evidence-governance` full-release gate.

The full matrix also runs every prior governance, runtime, ForgeOS, SDK, IDE, audit, benchmark, reconstruction, packaging, and archive-integrity gate.
