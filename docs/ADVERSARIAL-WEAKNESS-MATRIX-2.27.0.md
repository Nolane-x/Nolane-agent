# Forge Studio 2.27.0 — Adversarial Weakness Matrix

| Area | Implemented evidence | Remaining weakness |
|---|---|---|
| Shared state | Versioned typed entries, provenance, TTL, fencing and preserved conflicts | Large real-world swarm contention is not independently benchmarked |
| Commitments | Contract revisions, acknowledgements, handoffs, wait graph and deadlock recovery | Cross-organization negotiation and hosted identity remain outside local evidence |
| Topology | Solo/team recommendations constrained by risk, independence, trust and resources | Recommendations do not automatically launch or scale a production swarm |
| Semantic merge | API-assumption, behavior and duplicate-logic findings with confidence/provenance | Not a universal program-equivalence or whole-language semantic proof |
| Browser replay | Versioned scripts, seed, state reset, allowlists, injection/download guards and divergence receipts | No visual oracle and no cross-platform computer-use certification |
| Review | Risk/dependency ordering and scoped approval decisions | Hosted collaborative review workflows remain partial |
| Playback | Bounded event/checkpoint history and rewind plans | Rewind is not auto-executed and cannot replace Git/checkpoint verification |
| Steering | Revision- and capability-gated pause/resume/redirect/reprioritize/revoke | Distributed process interruption across every provider remains partial |
| Web/VS Code | Shared bounded mission-state projection and accessible progressive disclosure | JetBrains parity and full cross-repository IDE parity remain incomplete |
| UI performance | Virtualized/bounded panels, reduced motion and no heavy blur | Representative GPU/frame-time certification across hardware remains incomplete |
