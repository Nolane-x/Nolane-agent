# Roadmap

The roadmap advances through the 0.0.x line; it does not use historical milestone names.

## Next patch candidates
- **0.0.1:** real-machine validation on representative Windows/macOS/Linux hardware, including labelled 8 GB Windows coverage.
- **0.0.2:** structured dogfood benchmark covering long-running repository work, intervention rate, recovery and task-completion quality.
- **0.0.3:** release trust hardening: Windows signing verification, macOS signing/notarization evidence and Linux package-signing strategy.
- **0.0.4+:** measured autonomy improvements driven by failures from real-machine and dogfood evidence: planning, context compression/retrieval, verifier independence, recovery, persistent project memory and multi-agent coordination.

Patch numbers are planning slots, not promises; evidence may change ordering.
